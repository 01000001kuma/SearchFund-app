# Contributing to Search Fund Tool

First off, thank you for considering contributing to Search Fund Tool! It's a professional project designed to help search fund entrepreneurs identify high-quality acquisition targets in Spain.

## Code of Conduct
By contributing, you agree to maintain a professional and respectful environment.

## How to Contribute

### 1. Setup Environment
Ensure you have the environment configured as described in the [README.md](./README.md).

### 2. Development Workflow
- **Branching**: Create a feature branch for every change: `feature/description-of-change` or `fix/issue-number`.
- **Commits**: Use conventional commits (e.g., `feat: add new search filter`, `fix: resolve memory leak in Electron`).
- **Pull Requests**: Provide a clear description of the change and why it is necessary.

### 3. Coding Standards
- **Backend**: Follow PEP 8. Use type hints for all function signatures.
- **Frontend**: Use TypeScript strict mode. Follow the shadcn/ui design patterns.
- **Tests**: Every new feature must include a corresponding test in the `/tests` folder.

## Reporting Issues
Please use the issue templates provided in the `.github/ISSUE_TEMPLATE` directory to report bugs or request features.
